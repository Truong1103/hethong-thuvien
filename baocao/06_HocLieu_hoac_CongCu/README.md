# Học liệu và công cụ: mã nhúng HTML

Các file trong thư mục này là mã HTML minh họa để nhúng các chức năng chính của Thư viện Số Lá Xanh vào một trang giới thiệu hoặc LMS.

## Cách sử dụng

1. Mở file `.html` bằng trình duyệt để xem mã và bản xem trước.
2. Sao chép phần nằm trong thẻ `<iframe>` vào trang cần nhúng.
3. Nếu nền tảng không cho phép iframe, dùng liên kết dự phòng trong thẻ `<noscript>`.

## Danh sách

- `nhung-trang-chu.html`: nhúng trang chủ.
- `nhung-kho-sach.html`: nhúng kho sách.
- `nhung-chatbot-thu-ky.html`: nhúng chatbot thủ thư ảo.
